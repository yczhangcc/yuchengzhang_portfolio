## Claude Code

Use `AGENTS.md` as the shared source of truth for this repository. The resume formatting, page-density, bullet-count, and reverse-chronological ordering rules in `AGENTS.md` are mandatory.

Bullet hierarchy reminder: target-defining entries need 4-5 bullets, normal/common entries need 3 bullets, and only clearly low-priority supporting entries should stay at 2 bullets.

Targeted application resumes must stay one page. If they overflow, remove the least related entry first, then tighten formatting or wording; keep the master website CV as the 2-page exception.

Keep this file small so Codex and Claude Code do not drift into separate instruction sets.
