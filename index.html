CodeAssist: Full-Stack AI Feedback System

How do you give students real AI help without handing them the answer?

Data
Student code, uploaded files, test cases, and execution results from programming courses.
Method
React + Flask + PostgreSQL system where instructors set prompt templates, context permissions, model providers (OpenAI, Gemini, Claude, local), usage limits, and cooldowns per assignment. LLM context is filtered before every provider call.
Result
A working AI tutor for debugging, complexity, and test-case feedback that only sees what the instructor allows.
